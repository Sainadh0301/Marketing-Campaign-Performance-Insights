# 📊 Marketing Campaign Performance Insights

### Python | Pandas | NumPy | Matplotlib | Seaborn | Exploratory Data Analysis

---

## 📌 About the Project

The **Marketing Campaign Performance Insights** project focuses on analyzing digital marketing campaign data to evaluate business performance, customer engagement, marketing channel effectiveness, and Return on Investment (ROI).

Using Python and Exploratory Data Analysis (EDA), this project identifies patterns and trends in marketing campaigns to understand which factors influence conversion rates, customer acquisition costs, and campaign profitability.

The analysis aims to generate meaningful business insights that support better marketing decisions and improve future campaign strategies.

## 🎯 Business Objectives

- Evaluate the overall performance of marketing campaigns.
- Identify marketing channels with better engagement and ROI.
- Analyze customer segments and target audience behavior.
- Understand the relationship between acquisition cost and ROI.
- Identify companies and campaign types with higher conversion rates.
- Analyze campaign performance across different locations.
- Explore campaign trends over time.
- Identify factors that influence marketing effectiveness.

## 📂 Dataset Overview

**Dataset:** Marketing Campaign Data

**Source:** [Marketing Campaign Dataset – GitHub](https://raw.githubusercontent.com/ArchanaInsights/Datasets/main/marketing_campaign.csv)

The dataset contains marketing campaign information, including campaign details, customer segments, marketing channels, engagement metrics, acquisition costs, and ROI.

### Dataset Features

| Feature | Description |
|---|---|
| Campaign_ID | Unique campaign identification |
| Company | Company conducting the campaign |
| Campaign_Type | Marketing campaign category |
| Target_Audience | Intended audience |
| Duration | Campaign duration |
| Channels_Used | Marketing channels |
| Conversion_Rate | Percentage of conversions |
| Acquisition_Cost | Customer acquisition cost |
| ROI | Return on Investment |
| Location | Geographical location |
| Language | Campaign language |
| Clicks | Total clicks |
| Impressions | Total impressions |
| Engagement_Score | Customer engagement measurement |
| Customer_Segment | Customer classification |
| Date | Campaign date |

## 🔍 Project Workflow & Analysis

### 1. Data Exploration & Descriptive Analysis

- Load the dataset using Pandas.
- Understand dataset dimensions and structure.
- Check data types and dataset information.
- Generate descriptive statistical summaries.
- Identify unique campaign IDs.
- Analyze campaign types, locations, channels, and customer segments.

### 2. Campaign Performance Analysis

- Analyze Acquisition Cost vs ROI.
- Calculate Average Conversion Rate by Channel and Campaign Type.
- Compare Engagement Score by Campaign Type.
- Evaluate Average ROI by Company.
- Identify relationships between numerical variables using a Correlation Heatmap.

### 3. Customer Segmentation Analysis

- Analyze Target Audience Distribution.
- Identify Conversion Rates by Customer Segment and Language.
- Compare Acquisition Cost by Customer Segment and Channel.
- Evaluate Average Conversion Rate by Language.

### 4. Marketing Channel Effectiveness

- Compare Engagement Scores across Channels and Campaign Types.
- Analyze Total ROI by Marketing Channel.
- Compare Clicks and Impressions across different Channels.
- Identify effective marketing channels.

### 5. Time-Based Campaign Analysis

- Analyze Campaign Duration Distribution.
- Track Conversion Rate Over Time by Company.
- Evaluate Engagement Score Trends Over Time.
- Understand changes in campaign performance over time.

### 6. Geographical Performance Analysis

- Compare Average Acquisition Cost by Location.
- Analyze Conversion Rate by Location and Target Audience.
- Evaluate ROI Proportion across different Locations.
- Identify geographical differences in campaign performance.
